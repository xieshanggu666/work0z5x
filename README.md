# 家庭能源中枢：家庭能源与电费优化系统

模拟家庭一日/一月的用电场景：分时电价、光伏发电、储能电池与可迁移家电负荷联合调度，量化"峰谷套利 + 光伏自用"带来的电费节省。

## 快速开始

```bash
npm install
npm run dev
```

`npm test` 运行测试套件。

## 架构

```
home_energy/
├── engine/
│   ├── tariff.js    分时电价表 + 月度阶梯附加
│   ├── solar.js     光伏逐时出力预测（季节正弦 + 天气衰减）
│   ├── loads.js     基线负荷 + 可迁移家电（含跨午夜窗口）
│   ├── battery.js   储能调度（SOC 离散化动态规划）
│   ├── dr.js        电网需求响应：峰谷激励计划 / 报名 / 事件执行 / 幂等台账
│   └── sim.js       场景组装：当日模拟 / 月度账单（含 DR 联动与回写）
├── server.js        HTTP 服务
├── web/             Vue3 + Canvas 前端
└── tests/           引擎测试套件
```

## 核心语义

- **分时电价**：峰（8-11、18-22 点）1.02 元/kWh，平 0.63 元，谷（0-6 点）0.32 元；时段左闭右开。
- **阶梯附加**：月用电超 200 kWh 每度 +0.05 元，超 400 kWh 每度 +0.2 元，按档累计。
- **光伏模型**：出力 ∝ 装机 × 天气系数，日照时长随季节变化，夏季午后达峰。
- **负荷调度**：每个可迁移家电在允许窗口内贪心选择"净购电成本增量最小"的起始时隙；窗口可跨午夜。
- **电池调度**：动态规划在 SOC 网格（21 档）上搜索最小购电成本路径；充电计入效率损耗，放电按电池端功率约束；光伏优先自用、再充电、余电上网。
- **账单**：购电费 − 上网收益 + 阶梯附加。月度账单按确定性伪随机天气序列逐日模拟，遵循三条规则：
  - **SOC 逐日结转**：每日以"前一日末态电量"为初始状态（`soc_end_kwh → soc_start_kwh`），跨日不断档；日终残余电量按当日谷价计残值，避免存量电被当成零成本放空。
  - **阶梯整月统一计**：阶梯附加只在月末按整月购电量结算一次（无储能 / 含储能各按自身购电量），日明细只含当日分时能量电费，不存在重复计费。
  - **日明细可复算**：日明细的 `energy_no_bat / energy_bat` 与 `/api/simulate` 传入对应日期天气、结转初态 `batterySocStartKwh` 与残值 `endValue` 的结果逐分一致。

## 电网需求响应（DR）

运营方发布**峰段削峰 / 谷段填谷**激励计划，家庭报名后，事件当日可迁移家电与储能电池按"调度信号价"联动调度；事件窗口相对基线少用（削峰）/多用（填谷）的电网电量按单位激励结算奖励，并幂等回写月度账单。

- **信号价与结算价分离**：`objPrices` 仅用于家电贪心与电池 DP 寻优（削峰窗口加价、填谷窗口压价），真实能量电费仍按原分时电价沿最优路径重算；激励不进能量电费、不进阶梯附加。
- **基线口径**：响应量 = 同日"无信号同配置"与"叠加信号"两种方案在事件窗口内的净购电量之差（含电池方案与含电池基线比，不与无电池曲线混淆）。
- **幂等结算**：执行结果按 `(家庭, 事件)` 冻结，月账单按 `(账期, 家庭, 事件)` 单列台账；重复执行/重复出账只回读首笔，不重复结算。量测失败冻结为 `failed`（奖励 0），不补结成功。
- **撤销 / 退出**：尚未执行的事件随即失效，当日按原规则计算且不结算；**已结算金额是历史事实，计划撤销不回滚**。
- **旧账单不变**：不传 `homeId`（或不注入台账）时月度账单行为与字段与旧版逐分一致，`dr` 块为 `null`；`cost_bat_after_dr = cost_bat − dr_reward`。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 系统信息（可迁移负荷、电价表） |
| POST | `/api/simulate` | 模拟单日（负荷/光伏/电池/逐时电网功率与 SOC） |
| POST | `/api/month` | 月度账单模拟与对比（带 `homeId` 时回写 DR 结算） |
| POST | `/api/dr/plans` | 运营方发布峰谷激励计划（`name/month/days[]/events[]`） |
| GET | `/api/dr/plans` | 计划列表（含状态） |
| POST | `/api/dr/plans/:id/revoke` | 撤销计划（未执行事件失效，已结算保留） |
| POST | `/api/dr/enroll` · `/api/dr/unenroll` | 家庭报名 / 退出 |
| GET | `/api/dr/home/:homeId?year&month` | 家庭报名与当月事件台账 |
| POST | `/api/dr/execute` | 执行事件：量测、联动调度、冻结结算（`telemetryFault` 模拟失败） |
| POST | `/api/dr/preview` | 事件日基线 vs 响应预览，不写台账 |
