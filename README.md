# 家庭能源中枢：家庭能源与电费优化系统

模拟家庭一日/一月的用电场景：分时电价、光伏发电、储能电池与可迁移家电负荷联合调度，量化"峰谷套利 + 光伏自用"带来的电费节省。

## 快速开始

```bash
npm install
npm run dev
```

`npm test` 运行测试套件。

## 架构

```
home_energy/
├── engine/
│   ├── tariff.js    分时电价表 + 月度阶梯附加
│   ├── solar.js     光伏逐时出力预测（季节正弦 + 天气衰减）
│   ├── loads.js     基线负荷 + 可迁移家电（含跨午夜窗口）
│   ├── battery.js   储能调度（SOC 离散化动态规划）
│   ├── sim.js       场景组装：当日模拟 / 月度账单
│   ├── dr.js        需求响应：信号价、事件评估、月度执行与回写
│   └── dr_store.js  计划/报名/撤销/结算状态机（幂等结算）
├── server.js        HTTP 服务
├── web/             Vue3 + Canvas 前端
└── tests/           引擎测试套件
```

## 核心语义

- **分时电价**：峰（8-11、18-22 点）1.02 元/kWh，平 0.63 元，谷（0-6 点）0.32 元；时段左闭右开。
- **阶梯附加**：月用电超 200 kWh 每度 +0.05 元，超 400 kWh 每度 +0.2 元，按档累计。
- **光伏模型**：出力 ∝ 装机 × 天气系数，日照时长随季节变化，夏季午后达峰。
- **负荷调度**：每个可迁移家电在允许窗口内贪心选择"净购电成本增量最小"的起始时隙；窗口可跨午夜。
- **电池调度**：动态规划在 SOC 网格（21 档）上搜索最小购电成本路径；充电计入效率损耗，放电按电池端功率约束；光伏优先自用、再充电、余电上网。
- **账单**：购电费 − 上网收益 + 阶梯附加。月度账单按确定性伪随机天气序列逐日模拟，遵循三条规则：
  - **SOC 逐日结转**：每日以"前一日末态电量"为初始状态（`soc_end_kwh → soc_start_kwh`），跨日不断档；日终残余电量按当日谷价计残值，避免存量电被当成零成本放空。
  - **阶梯整月统一计**：阶梯附加只在月末按整月购电量结算一次（无储能 / 含储能各按自身购电量），日明细只含当日分时能量电费，不存在重复计费。
  - **日明细可复算**：日明细的 `energy_no_bat / energy_bat` 与 `/api/simulate` 传入对应日期天气、结转初态 `batterySocStartKwh` 与残值 `endValue` 的结果逐分一致。

## 电网需求响应（DR）

运营方发布峰谷激励计划，家庭报名后联动可迁移家电与电池调度，执行结果回写月度账单与节省统计。

- **信号价 ≠ 结算价**：削峰事件在分时价上加激励、填谷事件减激励（截断到 0），只用于家电选位与电池 DP 选路；物理账单永远按真实分时价在被选路径上重算（`battery.energy_actual`），能量电费口径不被污染。
- **双链执行**：基线链（无 DR 调度）与响应链（按信号价调度）各自独立逐日结转 SOC；事件窗口按实际购电量对比，削峰响应量 = 基线购电 − 响应购电，填谷反之；奖励 = 响应量 × 激励，未达 `requiredKwh` 门槛的事件失败、奖励为 0。
- **回写而不覆盖**：`runMonthDr` 返回的顶层字段与 `/api/month` 旧账单逐分一致；DR 结果只写入新增的 `dr` 块，最终应付 = 响应链账单 − 奖励，奖励只冲减一次。
- **不重复结算**：结算单按 `homeId:planId` 缓存，成功/失败/撤销后再次结算原样返回同一结算单（`repeated:true`）；撤销生成零奖励、`bill:null` 的留痕单，旧账单不受影响。成功结算后计划与报名均不可撤销。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 系统信息（可迁移负荷、电价表） |
| POST | `/api/simulate` | 模拟单日（负荷/光伏/电池/逐时电网功率与 SOC） |
| POST | `/api/month` | 月度账单模拟与对比 |
| POST | `/api/solar` | 光伏逐时出力 |
| GET | `/api/dr/plans` | 需求响应计划列表（启动时内置一份夏季峰谷计划） |
| POST | `/api/dr/plans` | 运营方发布计划（事件窗口、激励、门槛、生效日、锁定场景） |
| POST | `/api/dr/plans/:id/cancel` | 撤销计划（有成功结算时 409） |
| POST | `/api/dr/plans/:id/enroll` | 家庭报名（联动家电、是否联动电池、报名场景快照） |
| POST | `/api/dr/plans/:id/enroll/cancel` | 家庭撤销报名（幂等；成功结算后 409） |
| POST | `/api/dr/plans/:id/settle` | 执行结算并回写账单（幂等，返回同一结算单） |
| GET | `/api/dr/plans/:id/bill?homeId=` | 查询结算单 |
| POST | `/api/dr/preview` | 单日联动预览（不结算、不留痕） |
